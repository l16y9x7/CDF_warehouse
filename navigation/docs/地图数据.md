# 地图数据

nav 不接 MQTT。口给 Gateway 调，云端只和 Gateway 说话。

| 链路 | 状态 |
|---|---|
| 建图：开始、遥控、结束，再把图交回云端编辑 | 未做，第 4 节 |
| 下发：编辑好的图写回底盘 | 已做，第 3 节 |
| 上报站点、路径 | `GET :8001/state` 的 `map`，约 1 秒一次进 OSD `data.map` |
| 上报栅格 | 换图时 `POST /load_map`，再 `POST robotDog/map`。没有站点、没有路径 |

## 1. 站点与路径

`GET :8001/map` 和 `/state` 的 `map` 一样。没有栅格。

```json
{
  "map_id": "test_zhongmian",
  "stations": [
    {
      "station_id": "SORTING_BASKET_3",
      "name": "SORTING_BASKET_3",
      "vendor_id": "1",
      "x": -0.378,
      "y": 0.148,
      "yaw": 3.1662,
      "aliases": ["SORTING_BASKET_3", "1"]
    }
  ],
  "nodes": [
    {"id": 1, "x": -0.235, "y": 0.239, "yaw": 0, "desc": ""}
  ],
  "edges": [
    {
      "id": 1,
      "type": 1,
      "s_node": 1,
      "e_node": 2,
      "sx": -0.235, "sy": 0.239,
      "ex": -0.236, "ey": 0.655,
      "cost": 0.416,
      "robot_direction": 4,
      "rotate_direction": 1
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `x` `y` `sx` `sy` `ex` `ey` `cost` | 米。底盘文件是毫米，nav 除 1000。网页厘米 = 毫米 / 10 |
| `yaw` 以及路径朝向 | 弧度。底盘值绝对值大于 10 时先除 1000，否则已是弧度 |
| `name` | Gateway 补的，等于 `station_id` |
| `vendor_id` | 底盘站点号 |
| `aliases` | `station_id` 和底盘站点号 |
| `cost` | 不是枚举，等于起终点距离。现场 `113.3`–`421.3` mm，即 `11.33`–`42.13` cm，上报是米 |

| 网页 | 字段 | 能取的值 | `test_zhongmian` |
|---|---|---|---|
| 站点类型 | `station.type` | `1` 默认，`2` 充电桩，`3` 停靠点，`4` 工作站点，`5` 库位站点，`6` 避让站点，`7` 货架站点，`255` 自定义 | 全是 `1` |
| 车头朝向 | `edge.robot_direction` | `1` 前进，`2` 后退，`3` 路径左侧横移，`4` 路径右侧横移，`16` 自定义（配 `orientation`）。SDK 另有 `33`（`0x21`）货架腿识别，网页常量里没有 | `1` `2` `3` `4` |
| 旋转方向 | `edge.rotate_direction` | `0` 未指定，`1` 逆时针，`2` 顺时针 | 全是 `1` |
| 路径类型 | `edge.type` | `1` 直线，`3` 贝塞尔。协议里还有 `0` 零，`2` 圆弧（废弃），`4` 旋转 | 全是 `1` |
| 路径行为 | `edge.path_behavior.type` | `0` 默认，`1` 以上视二维码为运动中心对接 | 全是 `0` |
| 路径行为阶段 | `path_behavior.trigger_stage` | `0` 默认，`1` 进入前 | 全是 `0` |
| 路径行为载货 | `path_behavior.trigger_condition.load_state` | `0` 无，`1` 空载，`2` 满载 | 全是 `0` |
| 执行类型 | `edge.param` | 现场全是 `255`，网页显示 `EXECUTE_ALL`。协议和网页包里没有这份枚举 | 全是 `255` |

## 2. 栅格

```json
{
  "sn": "设备号",
  "timestamp": 0,
  "map_id": "云端UUID",
  "info": {
    "width": 742,
    "height": 906,
    "resolution": 0.02,
    "origin": {
      "x": -5.3,
      "y": -3.3,
      "z": 0,
      "position": {"x": -5.3, "y": -3.3, "z": 0}
    }
  },
  "data": [0, 100, -1]
}
```

| 字段 | 说明 |
|---|---|
| `map_id` | 云端 UUID，不是底盘图名 `test_zhongmian` |
| `info.width` `info.height` | 格数。现场 `742×906` |
| `info.resolution` | 米/格。现场 `0.02`（2 cm/格） |
| `info.origin` | 米。现场 `(-5.3, -3.3)` |
| `data` | 长度 = `width * height`。`0` 空闲，`100` 占用，`-1` 未知 |

## 3. 下发导入底盘

已做。`POST http://127.0.0.1:8001/maps/import`。坐标是毫米。

```json
{
  "map_name": "nav_upload",
  "switch": false,
  "topology": {
    "meta": {
      "length_unit": "mm",
      "angle_unit": "1/1000 rad",
      "resolution": 2,
      "size.x": 10,
      "size.y": 10,
      "zero_offset.x": 5,
      "zero_offset.y": 5,
      "version": "1.13.0"
    },
    "data": {
      "node": [
        {"id": 1, "x": 0, "y": 0, "yaw": 0, "desc": ""},
        {"id": 2, "x": 40, "y": 0, "yaw": 0, "desc": ""}
      ],
      "station": [
        {
          "id": 1,
          "name": "NAV_TRY",
          "type": 1,
          "node_id": 1,
          "edge_id": 1,
          "pos.x": 0,
          "pos.y": 0,
          "pos.yaw": 0,
          "desc": ""
        }
      ],
      "edge": [
        {
          "id": 1,
          "type": 1,
          "s_node": 1,
          "e_node": 2,
          "sx": 0, "sy": 0,
          "ex": 40, "ey": 0,
          "cx": 0, "cy": 0, "dx": 0, "dy": 0,
          "limit_v": 0,
          "limit_w": 0,
          "s_facing": 0,
          "e_facing": 0,
          "orientation": 0,
          "rotate_direction": 1,
          "direction": 1,
          "robot_direction": 1,
          "param": 255,
          "is_back_edge": false,
          "cost": 40,
          "radius": 0,
          "desc": ""
        }
      ]
    }
  }
}
```

| 字段 | 说明 |
|---|---|
| `map_name` | 必填。字母、数字、`_`、`-`。不能以数字结尾，否则底盘从 `{图名}0.pgm` 认不出图名（`90002`）。不能是正在定位的图 |
| `switch` | 可选，布尔，默认 `false`。`false` 只写入地图目录。`true` 导入后按 nav 当前位姿切过去：底盘取消定位，再按这个位姿重新定位 |
| `topology` | 必填。底盘那份 json。`data.station` / `node` / `edge` 的取值见第 1 节，坐标改用毫米 |
| `meta.length_unit` | `mm` |
| `meta.angle_unit` | 文件写 `1/1000 rad`。同一张图里绝对值小于 10 的朝向已经是弧度 |
| `meta.resolution` | `2` 表示 2 cm/格 |
| `meta.size.x` `meta.size.y` | 格数，必须和 pgm 宽高一致 |
| `meta.zero_offset.x` `meta.zero_offset.y` | 原点在第几格。写进 pgm 头的 `#` 注释 |
| `meta.version` | 现场 `1.13.0`，nav 把它当作底盘 `base_version` |
| `node.x` `node.y` `station.pos.x` `station.pos.y` `edge.sx` `sy` `ex` `ey` `cx` `cy` `dx` `dy` `cost` `radius` | 毫米 |
| `station.pos.yaw` `edge.s_facing` `e_facing` `orientation` | 和底盘文件一致。现场混用弧度和千分之一弧度 |
| `data.edge` | 空数组可以导入，但这张图在底盘上没有路径 |

nav 按 `meta` 生成 `{图名}0.pgm`，和 `topology` 打成 gzip 后交给底盘 `POST /api/v0/map/import`。调用方只交上面的 JSON。

| pgm 行 | 说明 |
|---|---|
| `P5` | 二进制灰度图 |
| `#5` | `zero_offset.x` |
| `#5` | `zero_offset.y` |
| `#2` | `resolution` |
| `10 10` | 宽、高，等于 `meta.size` |
| `255` | 灰度最大值。后面每个格子 1 字节 |

上面是试导入的 10×10 图。`test_zhongmian` 是 `#265`、`#741`、`#2`，`742 906`。没有这三行 `#` 注释，底盘回 `90004`。png、缩小图、lom、md5 不用传，底盘自己补。

## 4. 建图（未做）

建图时没有站点，不能用 `/goto`。图名规则同第 3 节。

```text
POST /maps/drawing/start
{"map_name": "new_map"}

POST /maps/manual
{"vx": 0.2, "vy": 0, "w": 0}

POST /maps/drawing/finish
{"map_name": "new_map"}

POST /maps/drawing/cancel
{}
```

| 字段 | 说明 |
|---|---|
| `map_name` | 开始和结束用同一个名字。底盘 `CMD_NEW_MAP_START` / `CMD_NEW_MAP_STOP` 的参数 |
| `vx` `vy` | 米/秒。nav 乘 1000 变成底盘毫米/秒。必须先进入手动模式 |
| `w` | 弧度/秒。nav 乘 1000 变成底盘千分之一弧度/秒 |
| `vx` `vy` `w` 全 `0` | 停车 |
| `cancel` | 不保存。底盘 `CMD_NEW_MAP_CANCEL` |

`finish` 之后 nav 导出这张图。Gateway 把 `topology` 上云，结构和第 3 节相同，坐标毫米。云端改完站点和路径，再走第 3 节。上云地址未定。不要用 `robotDog/map`，那个只有栅格。
