# 底盘网页：取消定位之后再定位

取消定位只停掉当前位姿，**地图还在**，不用重新建图。

协议要求再定位必须先给一个初始位置，再点启动。只点「启动定位」、不在图上给位置，会报 SLAM 状态异常（错误码 10002），一直定不上。

## 打开网页

71 网直接开 `http://192.168.71.50`。只在 130 网时：

```bash
ssh -L 8080:192.168.71.50:80 admin@192.168.130.105
```

浏览器开 `http://127.0.0.1:8080`。账号 `admin` / `admin`。确认当前图仍是 `test_zhongmian`。

## 再定位（二选一）

**按位置（人把车停在图里某个看得到的地方）：**

1. 在地图上点车实际站的位置，拖出车头朝向，和现场一致。这一步是「设置初始位姿」。
2. 再点启动定位。
3. 等激光和墙对上、车标稳住。点的位置和真车差太远会对不上，把车挪到墙角、货架这类好认的地方再点一次。

**按站点（车就停在某个站点上）：**

选当前这个站点，用站点定位。站点必须是这张图上已有的，不存在会失败（错误码 10003）。

旁边留人，手能按急停。定位成功后平台可以再发导航。
