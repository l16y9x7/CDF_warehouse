### Local ONNX export for OpenCV 5

`sr.onnx` is an equivalent export of the above `sr.prototxt` / `sr.caffemodel`,
generated by `../tools/convert_wechat_sr_to_onnx.py`. It retains the original
weights and architecture, including the top-left crop in the residual branch.
The original model's license in `LICENSE` applies.

- Format: ONNX opset 11, IR version 7, dynamic spatial input dimensions.
- Input: `data`, float32 `[1, 1, H, W]`; output: `fc`, `[1, 1, 2H-1, 2W-1]`.
- SHA-256: `c0bcb931a8247f83152ef4bdda342334cf9721e70f3174da512559a2f953c6c4`.
- Validated against the original Caffe network at three non-square input sizes;
  maximum absolute output difference was `5.42402267e-06` for the seeded inputs.
- Tested through `BarcodeDetector` with OpenCV 5.0.0 on synthetic and archived barcodes.

OpenCV 4 continues to use the original two Caffe files. OpenCV 5 uses only
`sr.onnx`; conversion packages are not needed on the deployment machine.
