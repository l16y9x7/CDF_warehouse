罐类（右臂，普通流程）：确认夹爪完全张开 → 预抓取 → 抓取 → 合爪 → 右臂沿躯干 SDK Z+40 mm → 右臂沿躯干 SDK X−后退 (d+20) mm → 右臂沿躯干 SDK Z+75 mm → 上身沿躯干 SDK X−后退 100 mm → 结束。躯干运动时双臂和头部保持关节不动。

          
方盒（左臂，普通流程）：确认吸盘关闭 → 预抓取 → 抓取 → 下降到“下压”标定高度 → 打开吸盘 → 提起到“提起”标定高度 → 左臂沿躯干 SDK X−后退 (d+30) mm → 躯干后退100 mm。下降和提起仅改变躯干 SDK Z，保持 X/Y 和姿态；后续保持吸盘打开。

          
抓取段不可达时，依次尝试躯干前移 A=50/100/150/200 mm，与对应手臂同步到抓取点。抬升后右臂相对肩部退 (d+20−A) mm、左臂退 (d+30−A) mm：右臂配合躯干同步退 A mm，两者到位后右臂再抬升75 mm，到位后躯干独立后退100 mm；左臂配合躯干同步退 A mm，再单独躯干后退100 mm。手臂退距为负时表示相对肩部前伸。

          
手臂各段均使用终点躯干保护 MoveL：首段使用对应手臂输入臂角（留空取实测值），后续每段重新回读臂角。全部运动使用开始时网页已保存的平移与旋转速度。缺少前挡板平面时拒绝抓取。动作位姿保存于独立标定文件，删除网页记忆点不会影响流程。

          
夹爪随顶部总控制解锁和锁定；自动闭合前需完成夹爪初始化。点击时按当前躯干重新转换已显示的估计结果。保护段仅检查终点肘部；中途失败或停止即取消后续动作。
